# LaunchKit SaaS Landing Page

A modern 4-page SaaS website built with **Tailwind CSS + Vanilla JavaScript**, designed with a Framer-style aesthetic.

## ✨ Overview

LaunchKit is a premium SaaS landing page template featuring a clean, minimal, and high-conversion design inspired by modern tools like Notion, Stripe, and Linear.

It includes:

* Landing page (Home)
* Features page
* Pricing page
* About page

## 🛠 Tech Stack

* HTML5
* Tailwind CSS (CDN)
* Vanilla JavaScript
* Google Fonts (Inter)

## 🎨 Features

* Framer-style UI design
* Glassmorphism cards
* Smooth scroll animations
* Responsive layout
* Pricing toggle (monthly/yearly)
* FAQ accordion
* Bento-style feature grid
* Modern SaaS hero sections
* Clean typography system

## 📁 Pages

```
/index.html      → Home / Landing Page
/features.html   → Product Features
/pricing.html    → Pricing Plans
/about.html      → Company Info
```

## 🚀 Getting Started

1. Download or clone the project
2. Open `index.html` in your browser
3. No build tools required

```bash
# optional local server
npx serve
```
